What Prompt Precision Bought in 24 Agent Trials

By Josiah Hunter•October 2, 2026•30 min read

First published October 2, 2026; revised October 9, 2026.

TLDR

  • Observed: All 24 trials met the full intended specification on the first pass. No correction, timeout, error, or clarification request occurred, and every run executed its provided check.
  • Observed: Spelling-error runs stayed within 2% of clear mean output. Reduced-grammar runs used 5% more output for Task A and 18% more for Task B. Ambiguous-rule runs used 9% more for Task A and 27% more for Task B.
  • Interpretation: Ambiguous rules transferred rule selection to the agent. The selected conventional defaults matched the intended rules, but unconventional intent was not tested, so ambiguity was not shown safe.
  • Observed: This was a small experiment with one model and harness, two synthetic tasks, four conditions, and three repetitions per task-condition cell. The 24-of-24 result created a ceiling that prevented detection of outcome differences.

What the 24 trials changed

Observed: The experiment used claude-sonnet-5-5 through Claude Code CLI 2.1.287 at high effort. It covered two small synthetic tasks, four prompt conditions, and three repetitions per task-condition cell. Task A summarized orders by region. Task B repaired a billing-proration function. Independent validators recomputed the intended answers from frozen fixtures, and every run executed its provided check after the final file change. The models later used to write and review this article were not trial models.

Observed: The conditions were clear instructions, spelling errors, reduced grammar and punctuation, and ambiguous governing rules. The spelling variant misspelled about one in three ordinary words while leaving identifiers intact. The reduced-grammar variant removed punctuation, capitalization, and many function words. The ambiguity variant replaced an explicit rule with a vague sentence.

Interpretation: These were three different manipulations, not one scale from bad English to good English. Spelling and grammar changed the surface form of the instructions. Ambiguity changed who selected an important rule.

Spelling errors left the measured result unchanged

Observed: All six spelling-error runs succeeded. Mean output was 1,277 tokens for Task A versus 1,254 for clear, and 693 for Task B versus 700 for clear. Both means were within 2% of clear. Tool and turn behavior was broadly comparable, and no run mentioned the misspellings.

Interpretation: On these tasks, this model read through the tested misspellings. The experiment did not test errors in identifiers, paths, numbers, negations, or domain terms. A typo in one of those places could change the instruction itself.

Reduced grammar preserved the result but not identical output

Observed: All six reduced-grammar runs succeeded. Mean output was 1,317 tokens for Task A versus 1,254 for clear, a 5% difference. For Task B, the mean was 823 versus 700, an 18% difference.

Observed: One early Task B run, T01, made an extra Bash call to read the tests and produced 996 output tokens. The other two produced 732 and 740, so T01 accounts for most of the Task B gap.

Interpretation: The prompts remained understandable in these tasks, but the design did not isolate grammar as the cause of the output difference. Turn behavior and ordinary run-to-run variation remain possible explanations.

Ambiguous rules turned instructions into agent choices

Observed: The ambiguous Task A prompt said:

Leave out any orders that shouldn't count.

Observed: The ambiguous Task B prompt said:

Make sure the amounts come out right.

Observed: All six ambiguous runs reached the intended result. Task A selected completed orders, normalized statuses, and deduplicated records. Task B used inclusive billing days and half-up rounding. No run asked for clarification. Under the broad manual coding used for the final messages, four of six messages flagged a judgment or explained a choice beyond the tests.

Interpretation: The selected conventional defaults matched the intended rules. That explains the bounded result, not the success mechanism. The experiment did not test intent that departed from convention, so it did not show that ambiguity is harmless.

Observed: Ambiguous prompts produced 1,370 mean output tokens for Task A versus 1,254 for clear, a 9% difference. For Task B, they produced 889 versus 700, a 27% difference. Final messages were also longer: 993 versus 930 characters for Task A and 809 versus 569 for Task B.

Interpretation: The experiment did not identify which additional tokens were explanatory or establish ambiguity as the cause of the difference. It did show the practical cost of leaving a governing rule to the agent: even a correct conventional choice remains an agent-selected choice.

Tokens and historical API-equivalent estimates

Observed: Input-side totals changed little with wording except in two Task B runs with an extra turn. Total uncached input, cache-write, and cache-read tokens ranged from 33,569 to 35,902 per Task A run. Task B normally ranged from 22,642 to 22,825, except for totals of 31,318 and 31,173 in the two extra-turn runs.

Interpretation: Turn count is a plausible explanation for the larger Task B totals, but this design did not isolate causality from prompt wording.

Calculated estimate: Using the official Claude pricing retrieved on October 2, 2026, individual API-equivalent estimates ranged from $0.0131 to $0.0369. Mean estimates across both tasks were $0.0241 for clear, $0.0241 for spelling, $0.0257 for reduced grammar, and $0.0242 for ambiguous. The 24-trial total was $0.5890. These are API-equivalent estimates, not charges. Observed: The subscription runs produced no per-request billed cost, and subscription utilization could not be separated by trial.

Calculated estimate: Mean API-equivalent cost per successful completion ranged from $0.0281 to $0.0334 for Task A and from $0.0155 to $0.0202 for Task B, depending on condition. Because every trial succeeded, the mean per-success estimate equals the mean per-trial estimate in this sample.

Calculated estimate: The additional ambiguous-condition output corresponded to about $0.001 to $0.002 per task at the locked output price, based on 117 additional tokens for Task A and 190 for Task B.

Calculated estimate: Condition-level estimate differences were smaller than within-condition spread. Observed: Cache writes ranged from 492 to 4,376 tokens per run, and the earliest Task A run in every condition had the most cache writes.

Interpretation: Cache-write timing appears important, but the experiment did not isolate cache timing, turn count, or wording as causes.

Calculated estimate: Under the stated workload, model, settings, cache behavior, historical prices, and observed success rates, 1,000 comparable tasks project to about $24 to $26 per condition. The projected success counts use the observed 100% rate and are optimistic. With six successes in six trials per condition, the one-sided 95% exact binomial lower bound is 0.05^(1/6) = 0.606962 under independent trials with a common success probability. It is not a real-world guarantee.

Observed: The experiment used one model and harness, two small synthetic tasks with conventional intended answers, four conditions, and three repetitions per cell. Sampling settings were not exposed by the CLI. Cache-timing noise remained. Subscription use was not separable by trial. The all-success result created a ceiling effect, so the experiment could not detect outcome differences.

A specification checklist

Interpretation: For the following checklist, prompt precision should be spent first where a wrong decision would matter.

  • Governing rules: State the rule the agent must apply.
  • Exceptions: Identify cases that do not follow the default.
  • Invariants: Name what must remain unchanged.
  • Success checks: Define how the result will be validated.
  • Surface clarity: Keep spelling and grammar clear enough to carry those rules.

Interpretation: This is a bounded decision rule for the tested model, harness, tasks, and prompt variants. It is not a universal prompting framework. The evidence does not show that spelling and grammar never matter, or that ambiguity is safe when the intended rule is unconventional or difficult to detect.
