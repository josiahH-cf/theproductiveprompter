Operations Park: Following Northstar Cloud Through FedRAMP 20x

By Josiah Hunter•November 26, 2026•3 min read

Open Operations Park and choose Start guided tour. In the first exercise, fictional cloud provider Northstar Cloud has put together an evidence packet. Who should check it? Pick the independent assessor and read why that handoff happens before a certification decision. If you pick another role, the exercise explains the choice and lets you try again.

Follow Northstar Cloud through Operations Park

Keep an eye on Northstar Cloud’s Service evidence ledger as you move through the tour. Early on, you establish the service’s profile and see what evidence can support a security claim. Later, a vulnerability shows up in the same service’s record. By then you have enough context to ask what changed, who needs to respond, and what evidence the next person will need to review. The same ledger follows the service into incident communication, significant changes, and ongoing review.

  1. Why FedRAMP 20x exists, including purpose, roles, and profiles.
  2. How a security claim becomes proof through evidence.
  3. What happens when a vulnerability appears.
  4. When an incident or major change occurs.
  5. How trust stays current through ongoing assurance.

Each step starts with a practical question and explains why it matters in plain English. See it happen shows the activity, Try it gives you a decision to make, and Official details gives you the terminology and sources behind the example. When you get to the vulnerability module, try pausing to explain what the finding adds to the service’s record and what the earlier evidence still tells you.

Why Operations Park became a guided simulation

The first version put twelve scene buttons and a set of reference tools on the opening screen. A newcomer had to work out where to begin before seeing what the material was for. The redesign gave the tour a clear starting point, grouped those scenes into five modules, and kept Northstar Cloud in view as its record changed. The project’s design review documents those choices as an inspection of the interface. It didn’t measure what learners took away.

The order gives each new event some context. You meet the people responsible for the service and its evidence before anyone has to act on a finding. Exact terms are still available when you need to follow a decision back to the source.

How the build keeps explanation connected to source material

The project preserves the original field guide and extracts its embedded data into src/data/source-data.json. The factual scenes live in src/content.js. The plain-English explanations and practice activities live in src/learning.js, with separate code for the interface and saved progress. That gives a wording edit and a factual correction different places to live. The project README maps those files to their roles.

The validation script extracts the original data again and checks that it exactly matches the generated copy. It also checks that all twelve scenes appear in the expected order, along with the content corrections and source references. The GitHub Pages workflow runs validation and tests before Vite builds the static site for deployment.

What I got out of it

I noticed it produced some useful content in learning - it also helped me consolidate information and share it publicly with my team members. it also gave me better visuals as to how the story works.

For a team discussion, try working through one scene together and asking each person what changed in Northstar Cloud’s record. The evidence-packet exercise is a good place to start because it gives the group a specific handoff to talk through.

Where Operations Park stops and current FedRAMP guidance begins

The project’s content validation record is dated August 11, 2026 and covers supplied FedRAMP Consolidated Rules version 2026.07.14.01. The preserved source declares 225 rules and includes full text for 60. The remaining statements are outside the simulation’s embedded rule coverage.

Use Northstar Cloud as a teaching example. When you need to make a decision about a real cloud service, check the current FedRAMP 20x program guidance and the applicable rules. The official Consolidated Rules changelog records releases after the version used to validate Operations Park.
